### E5 迁移指引（剩余 13 个文件怎么改）

统一从 `test/support/source.ts` 取源码，不再各自 `readFileSync`：

```ts
import { readSource, hasNoCode } from '../support/source'
const queueSource = readSource('components/player/player-queue.tsx')
```

三条规则：

1. **断言里不要写换行与缩进**。读取结果已折叠空白，写 `if (mode === 'list') { setIsListAtTop(true)`，
   不要写 `"if (mode === 'list') {\n      setIsListAtTop(true)"`。
2. **「禁止出现 X」一律用 `hasNoCode`**。读取结果已去注释，所以注释里提到被禁写法不会再误报
   （这正是当初 B2 被卡住的原因）。
3. **能抽成纯逻辑的就别断言源码**。范例：跑马灯几何 → `lib/marquee-policy.ts` + 行为单测；
   搜索联想行 → `lib/search-suggestions.ts` + 行为单测。
   判断标准：如果一段断言在「逻辑不变、只是挪了位置」时会挂，那它就该被抽出来测行为。

**已知需要特殊处理的文件**：`theme-runtime.test.ts:54` 用了 `/import \{[^\n]*\bcolors\b[^\n]*\}/`
这类跨行正则 —— 折叠空白后 `[^\n]*` 会跨整文件匹配，迁移时必须把正则改写成基于单行的形式
（或继续用 `readRawSource`）。

## 二期关键约束（必须先告知用户）

> **约束 1（歌单顺序）**：后端**没有** reorder / move-track / sort / import / export / m3u 端点，歌单顺序只由 `trackAddedAt` 递增决定。
> 因此导入的「顺序」只能是**按导入顺序追加的近似**，**无法持久化手工调整的顺序**。

> **约束 2（下载格式）**：离线下载**只支持原生可播格式**（flac / mp3 / m4a / wav / aac / alac / aiff / caf）。
> WMA / APE / DSD 这类需服务端转码的格式，转码产物是 HLS 分片（fMP4，2 秒一片），**无法直接当单文件下载**，因此不支持离线。
> 这条要写进 UI 文案，否则用户会以为「下载按钮坏了」。

> **约束 3（外部歌词源）**：主流外部源（如 LRCLIB）提供的是**整行**级 LRC，**不是逐字**。
> 因此**逐字歌词只能来自飞牛服务端**，外部源只能补 T2（整行）/ T3（纯文本）的空缺。
