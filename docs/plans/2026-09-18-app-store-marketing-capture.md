# App Store 营销截图重拍

## 需求摘要
基于转化率叙事，为轻简音乐建立可复现的 iOS 模拟器营销截图流程，使用审核测试服务器中的原创合成曲库，突出 NAS 私有曲库、随心漫游、歌词、音质、搜索和隐私，再更新 App Store 宣传图。

## 验收标准
- [x] 使用 iPhone 17 / iOS 26.5 和中文测试登录态重拍营销画面。
- [x] 产出曲库、播放器、全屏歌词、专辑音质、搜索结果等核心原始图。
- [x] 截图包含真实状态栏和安全区，并在商店设备框层统一补齐 Home Indicator。
- [x] 商店图前三张明确传达：NAS 私有曲库、随心漫游、沉浸歌词。
- [x] 完成 typecheck / lint 与截图视觉核对。
- [x] 产出 App Store 所需的 4 种 iPhone 尺寸导出包。

## 方案选择
- 选定方案：基于 Expo Router 深链 + `simctl` + 现有模拟器触摸工具的外部捕获脚本。
- 理由：不修改生产界面和导航，复用现有登录态和真实曲库，改动最小。
- trade-off：坐标捕获依赖指定模拟器；脚本会固定机型并用截图/OCR 验证防止误捕。暂不构建侵入式 DEBUG 页面。

## 变更范围清单
- 将新增：`apps/mobile/scripts/capture-marketing.sh`（模拟器捕获编排）。
- 将修改：App Store 截图工程的项目 JSON，更新文案、截图与布局。
- 可能修改：App Store 截图工程的 iPhone 设备框，仅用于补齐 Home Indicator。
- 明确不碰：生产路由、播放控制器、后端 Provider、现有页面样式、用户未提交的其他文件。
