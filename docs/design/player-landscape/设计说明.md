# 轻简音乐 · 播放器横屏沉浸体验设计说明

## 1. 品类定位与场景任务

- **品类**：个人高品质流媒体 / 本地高保真音乐播放器（iOS / iPadOS）。
- **使用场景**：
  1. **桌面立架伴听（StandBy Mode）**：将手机横放在桌面支架、无线充电座上，作为现代桌面声光时钟与艺术陈列摆件；
  2. **深度聆听与大视野歌词唱听**：双手横屏握持或夜间独处时，享受高保真封面、双语大字号歌词滚动与精准声学监控；
  3. **车载横屏支架**：大触控区、清晰的信息辨识与低干扰的沉浸界面。
- **痛点反思**：
  - 传统播放器横屏只是把竖屏粗暴拉宽，左右元素挤压拉扯，失去焦点；
  - 控件铺满全屏，缺乏呼吸感与留白，破坏了桌面陈列的静谧陪伴属性；
  - 缺少针对横屏视距较远的排版层级优化。

## 3. 三个独立设计方向

### 方向 01：【桌面伴听 · 流体光影】（推荐首选）
- **设计北极星**：将手机横屏化为一件有呼吸感的现代桌面声光艺术摆件。
- **构图与骨架**：
  - **4.2 : 5.8 双联屏非对称结构**。
  - **左侧（视听重心）**：超大尺度圆角悬浮封面（230×230，圆角 22px），后衬随曲目主色呼吸的流体弥散氛围光晕，带有轻微 3D 浮动感；曲名与艺人居中利落排布，附带 Hi-Res 无损角标。
  - **右侧（文字韵律）**：全高度动态失焦卡拉OK歌词瀑布。当前唱到的歌词为纯白、加粗（26pt / 700），前后各句呈高斯模糊失焦渐隐（光学景深模拟），随着节拍平滑滚动。
  - **控制系统**：底部半透明微胶囊悬浮岛。**支持 3.5 秒静置后自动弱化隐退至 20% 透明度**，轻触屏幕任意位置瞬间唤醒，将画面完全归还于音乐与光影。

### 方向 02：【黑曜典藏 · 机械唱机】
- **设计北极星**：将模拟时代的黑胶器物仪式感与现代精密数字微质感在横屏上重构。
- **构图与骨架**：
  - **5 : 5 黄金对等平衡构图**。
  - **左侧（机械舞台）**：黑曜石质感的微黑胶转盘（带微反光径向沟槽光泽与金属轴心），16 秒慢速匀速旋转；配备高精度的铝合金机械唱针（播放时压在黑胶上微颤，暂停时抬针归位）。
  - **右侧（专业控制台）**：曲目信息 + 真实跳动的音频频谱电平条（VU Meter / Spectrum Bars）+ 3 行居中高质感双语滚动歌词。
  - **控制系统**：微质感物理实体按键，带刻度的模拟进度标尺，手感沉稳有分量。

### 方向 03：【瑞士排版 · 录音室声学】
- **设计北极星**：剥离拟物与绚烂灯光，以严谨网格系统、声学全景波形与杂志级纯净排字呈现录音室极简美学。
- **构图与骨架**：
  - **3.8 : 6.2 偏心网格构图**。
  - **左侧（声学监测区）**：冷感方正画幅（带 1px 细发光边），精确时间码与等宽无衬线参数（44.1kHz • 24-BIT FLAC • STEREO）；**内嵌全景音频波形峰值轨**，已播放区域高亮，支持手指在波形上滑动精准 Scrub 定位。
  - **右侧（大字号歌词瀑布）**：参考经典瑞士平面排版，当前行放大至 28pt 粗黑体，行间距舒展透气，前置极简破折/点标。
  - **控制系统**：极简悬浮微条，纯面性图标，小巧无边框。

## 4. 横屏专属交互与系统适配

1. **传感器与屏幕旋转**：
   - 监听重力感应方向：竖屏到横屏触发平滑形态转场（封面由竖屏居中自适应缩放并滑动至左侧，歌词由底部升起并展开为双联右侧瀑布，总耗时 420ms，使用 Apple 级流体动量曲线）；
   - 在设置中提供「允许横屏沉浸模式」开关，并支持方向锁定。
2. **刘海 / 动态岛安全区避让**：
   - 横屏左置或右置时，自动检测 `insets.left` / `insets.right`，将内容容器水平缩进，确保封面或歌词不会被灵动岛遮挡；
3. **防误触与常亮策略**：
   - 横屏状态下默认开启 `KeepAwake`（屏幕不息屏）；
   - 边缘滑动手势需二次确认，避免桌面支架误触退出；
   - 提供纯净模式：双击屏幕任意空白处，瞬间隐藏所有控件，仅留封面与歌词。
