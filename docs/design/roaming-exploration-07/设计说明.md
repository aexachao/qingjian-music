# 漫游卡片探索 · 07

目标：让首页漫游入口有独立性格，同时不重复 mini 播放器的歌曲、歌手和播放控制。仅设计选型，未改 App 源代码。HTML 演示数据与几何封面用于保持各方向对比公平，非真实播放。

共同调性：安静、精细、中等密度、轻量、有一点器物趣味。来自用户已选择的柔和细环、对刺眼品牌红和实心中心的否定，以及希望移动端而非网页式首页的约束。只扩大一张漫游卡片，不放宣传文案与第二套播放按钮。390 × 844 手机视口，状态栏与底部播放器位置固定。新方案采用整宽卡片（166–191pt），喜欢/下载放下一排，因此会比现状多占约 80–100pt；可据选择再压缩。

| 方向 | 构图/引擎 | 记忆点 | 漫游中 | 放弃 |
|---|---|---|---|---|
| 现状 | 半宽卡片＋半露圆盘，基准 | 柔和细环 | 盘面慢转 | 封面、刻字 |
| 01 桌面黑胶机 | 拉丝金属×桌面，唯一非对称左右构图 | 右下角实体唱机 | 开播时物件转正少许，指示灯呼吸 | 多余唱机操作按钮；整张图片持续旋转 |
| 02 口袋电台 | 居中单物件，上方标题状态同一行 | 奶油灰背景中的酒红电台 | 侧边信号缓慢变化 | 假频率、频段旋钮交互、重新漫游 |
| 03 磁带随行 | 媒介即界面，整卡成为磁带 | 浅灰绿磁带、标签文字与双卷轴 | 两卷轴慢转 | 写实阴影堆叠、装饰性参数 |
| 04 声音轨道 | 满版轨道线＋居中宋体，主动离开音乐器材套路 | 轻轨迹上游走的单光点 | 光点沿椭圆缓行 | 唱片隐喻、丰富材质 |

保留系统字号用于首页、歌曲和导航；卡片标题分别使用系统20–24pt与宋体28pt。各方案色板、北极星与特征记录在 manifest。候选共享周边首页便于比较卡片，不把局部探索变成无授权的整页改造。

素材：黑胶机、电台由内置 image_gen 生成，无法指定或确认底层模型为 gpt-image-2.5；提示词见生成提示词.json，原始透明 PNG 位于 assets/。磁带和轨道使用可编辑 CSS 图形，基准唱片复用项目素材。未将这些素材写入正式 App。

交互：单张查看可以点卡片开始；开启后整卡不再触发操作。顶部“预览”区域可切换状态与浅/深色，它属于设计工具，不是 App 设计。mini 播放器的暂停键用于演示停止动效，不联网、不播放音频。减少动态效果通过 CSS 系统偏好关闭动画。开播/暂停是示意状态，未连接业务。

检查：浏览器实际查看全部方向；电台、磁带、轨道按390pt实际尺寸查看，黑胶机在并排的390pt画面检查。确认标题与状态没有重叠、所有方案保留喜欢/下载入口、最近播放与mini播放器。已操作电台状态切换、磁带开播和浅色切换、轨道开播。未做真机性能、业务状态、200%动态字体验收，未开展独立评审。本轮遵循方向探索先供用户选型，未由代理自行选定。

建议后续：用户选定后精修；如需要先优化候选，可做一轮独立视觉评审再调整，预计10–15分钟，1次评审调用，不新增生图调用（除非素材修改另有需要）。
